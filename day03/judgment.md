# TASK 3.1 — Workflow or Agent?

## 1. Classify incoming customer emails into five categories

**Decision: Workflow**

This is a predictable task because every incoming email only needs to be classified into one of five predefined categories. The cost of errors may be moderate, but because the process is simple and predictable, a workflow is more appropriate than an agent.

## 2. Resolve a customer's failed UPI transaction end-to-end across three internal systems, deciding the path as it goes

**Decision: Agent**

This is better suited to an agent because the system needs to investigate the failed transaction and decide which internal system to check and what action to take next. The cost of errors is high because an incorrect decision could affect a customer's money, so the agent would need appropriate controls and verification.

## 3. Generate a monthly account-summary paragraph from a fixed data table

**Decision: Workflow**

This is a predictable process because the input is a fixed data table and the required output is a standard account-summary paragraph. The cost of errors is relatively low and the steps can be predefined, so a workflow is simpler and more reliable than an agent.

## 4. Answer product FAQs from a knowledge base

**Decision: Workflow**

This is predictable because the system can retrieve relevant information from the knowledge base and use it to answer predefined types of product questions. The cost of errors can be moderate because incorrect product information may mislead customers, so a controlled workflow with reliable knowledge retrieval is preferable.

## 5. Research and compile a comparison of competitor credit-card offerings

**Decision: Agent**

This task is better suited to an agent because it requires researching different sources, deciding what information is relevant, and adapting the research based on what is discovered. The cost of errors can be significant because inaccurate competitor information could lead to poor business decisions, so the agent's results should be reviewed and verified.

## 6. Route an incoming call to the right department

**Decision: Workflow**

This is a predictable task because the system can identify the customer's intent and route the call to one of a predefined set of departments. The cost of errors is relatively low because a wrongly routed call can usually be redirected, so a workflow is more appropriate than an agent.
